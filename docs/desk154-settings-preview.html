电脑托盘该包办的（不该让你开终端）：
  • 开机自启 + 托盘常驻；插上设备自动认 MAC，不用选 COM 口。
  • 第一次：点「配对」→ 自动把本机局域网 IP 写进设备，不再手抄 host_url。
  • Wi-Fi：托盘里选家里的网、填一次密码，USB 推给设备（屏上不打字）。
  • 额度：托盘自己读 Cursor / Claude 登录态；缺 cookie 时弹一次「去登录」，不要改配置文件。
  • 刷机仍走电脑侧「更新固件」按钮，禁止误刷另一块板。
