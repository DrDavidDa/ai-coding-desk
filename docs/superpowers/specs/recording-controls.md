# Desk154 interaction invariants

## Recording controls (do not regress)

| Control | Meaning | While recording |
|---|---|---|
| Round **mic** | Talk | Tap again → end & send (or toggle per mode) |
| Round **square STOP** | End recording | **Send** (`voice_stop_and_send`) — **never cancel** |
| Top chip **取消** / PWR | Cancel | `voice_cancel` — discard |
| PLUS hold | Talk | Release → send |

The right round button is a **filled square** (Font Awesome stop / U+F04D), not a ban/prohibited glyph. Ban icon must not return.

Easter egg: long-press the **square STOP** (not SYNC, not 取消).
