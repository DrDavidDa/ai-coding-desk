# Desk154 给客户：开箱就能用

发给小白的不是源码，是 **一个 Windows 文件夹（或 zip）+ 已经刷好固件的设备**。客户电脑不需要安装 Python。

## 你交给客户的东西

| 盒子里 | 电脑网盘 / U 盘 |
|---|---|
| Desk154 本体（出厂已刷机） | `Desk154-Windows.zip` |
| **数据线**（必须能传数据，不要「仅充电」线） | 解压后双击 `Desk154.exe` |
| 本页打印成一张卡片更好 | 右下角托盘常驻即可 |

**不要**让客户自己烧录、不要 `pip`、不要填 IP。

打包命令（你在开发机上执行）：

```bat
cd /d E:\ai-coding-desk\host
powershell -ExecutionPolicy Bypass -File pack_windows.ps1
```

产物：`host/dist/Desk154-客户包/` ，打成 zip 发给客户。

## 客户三步（印在卡片上）

### 设备

1. 撕膜，插上 **盒子里的 USB 线** 到电脑（先亮屏再配对）。
2. 家里要用无线时，在向导里填 **Wi-Fi 名称和密码**（和手机上网那个一样）。不填也可以，一直插着线也能看额度、说话。
3. 额度页连晃三下抽签；其它页晃动不会响（避免揣兜里误触发）。摇一摇不能唤醒熄屏。
4. 没人碰超过 **5 分钟**会自动熄屏。中间 **PWR 按住约 1.2 秒**立刻熄屏；继续按到约 3 秒灯会闪一下，**松开才关机**（再按 PWR 开机）。点屏或按任意键可从熄屏唤醒；关机后只有 PWR 能开。插着 USB 时关机后主机可能掉线，再按 PWR 会回来。真拔电：拔 USB。

### 电脑（Windows 10/11）

1. 解压 zip，双击 **Desk154.exe**（杀毒软件拦截时选「仍要运行」）。
2. 向导点 **一键配对**。成功后右下角出现托盘图标。
3. 打开 Cursor / Claude 等你平时用的软件并登录——额度会自己出现在屏幕上。说话转文字如需使用，把 SiliconFlow Key 贴进向导（可以后再填）。

开机后程序会自己启动。设备设置里 **电脑** 一行显示 OK 即配对成功。

### 不会用时

- 配对提示找不到设备：换数据线、换 USB 口，等 5 秒再点配对。
- 屏不亮：先点一下屏幕或按一下按键（超过 5 分钟会自动熄屏）。仍不亮再确认线有电；必要时拔掉线等 10 秒再插。
- 额度全是横线：本机先打开并登录对应的 AI 工具，等一两分钟。
- 重新配对：托盘图标 → **重新配对**。

## 你这边出厂前（不是客户做的）

1. 只刷 MAC `28:84:85:56:EE:E0` 这一块（COM8 应用 / COM7 下载），**禁止**刷 COM9 / COM11 / PaperColor。
2. 确认额度页晃动抽签、其它页安静。
3. 把 `Desk154-Windows.zip` 和刷好的设备一起交给客户。
