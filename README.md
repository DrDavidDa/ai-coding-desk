# AI Coding Desk (Waveshare ESP32-S3-Touch-LCD-1.54)

Desktop companion: 3-key BLE HID + PTT + WS2812 status strip + 240×240 quota
pages for Claude Code, Codex, Cursor, and Zhipu GLM Coding Plan.

Secrets stay on the Windows host. The ESP32 only displays numbers and sends
keystrokes.

See [docs/ops-landing.md](docs/ops-landing.md) for how voice, the 3 keys, and the touchscreen actually work while coding.

See [docs/hardware.md](docs/hardware.md) and [docs/setup.md](docs/setup.md).
